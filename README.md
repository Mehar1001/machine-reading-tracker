# Store Machine Run App

React Native / Expo starter app for store visits, machine IN/OUT entry, run calculations, print reports, and employee visit history.

## Run

```bash
npm install
npm start
```

Then open with Expo Go or run on iOS/Android simulator.

## Included Features

- Stores screen with sidebar tabs: Stores and History
- Locate Me placeholder using Expo Location
- Store details screen
- Calendar-style date picker field using native date text entry fallback
- Four machine rows with Machine IN, Machine OUT, and camera buttons
- Auto Total IN, Total OUT, and Net Total
- RUN saves employee visit history
- Positive Net shows Submit & Print and Print
- Negative Net disables Submit & Print and allows Print only
- Run Results screen with Last Reading and Present Reading
- Total Net
- Store percentage and Vendor percentage manual inputs
- Auto-calculated Store/Vendor amounts
- Print Report using Expo Print
- Employee Visit History table

## Notes for developer

This is a functional frontend prototype. Replace mock stores, employee name, and local state with backend API/database later.
